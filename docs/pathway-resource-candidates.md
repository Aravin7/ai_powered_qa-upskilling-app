# QA pathway resource candidates

These are illustrative examples only. Following Aravin's dynamic-discovery amendment, the intended app researches resources using an LLM with provider-hosted web access for the selected direction and learning topic. This document is neither a fixed publisher allowlist nor the runtime resource inventory. Automatic checks and professional review must remain separately labelled.

Status: **research candidates only; not approved for learner plans**. Links were checked on 17 October 2026. A QA content owner still needs to confirm topic fit, level, accessibility, free/paid status, and last-verified dates before publication. The two items per topic follow the approved format: one documentation/reference page and one guided learning item (course, tutorial, or video). Where one source is reused across related topics, the reviewer should confirm that the specific section genuinely teaches that topic.

## Publication gate

These candidates do not make the existing `qa-synthetic-v1` catalogue reviewed. Each published topic needs a named reviewer, checked direct URL, publisher, access/cost note, a focused lesson/video deep link where possible, last-verified date, and approval record. The responsible-AI pair is explicitly incomplete. Until that review is recorded, suggestions may be shown only as provisional research and must not drive authoritative gaps or saved plans.
